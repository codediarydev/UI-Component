1 Accordion / FAQ

What is this component library for?

It's a collection of reusable HTML & CSS components you can drop into any project without writing them from scratch.

Do I need JavaScript to use these?

Most components work with pure CSS using tricks like checkboxes, radios, and the details/summary tags.

Can I customize the colors?

Yes - every components uses a small sets of CSS variables and classes that are easy to restyle.
