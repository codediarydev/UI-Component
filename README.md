# CodeNCraft

A collection of modern, responsive UI design components and pages built with plain HTML and CSS. This project focuses on reusable front-end sections for e-commerce, admin dashboards, login/signup flows, hero banners, product cards, and utility components.

## Project Overview

This workspace contains a set of standalone web pages and mini UI components designed to showcase clean interface patterns and polished styling. Each folder is structured as a separate design section, making it easy to study, reuse, and expand.

The project is ideal for:

- learning modern front-end layout design
- creating reusable UI patterns
- building landing pages and dashboard views
- practicing HTML/CSS structure and component styling

## Included Designs

### Main Pages

## Tech Stack

- HTML5
- CSS3
- Font Awesome icons
- Static front-end design files

This project does not currently use a framework or package manager; it is built as a lightweight static UI showcase.

## How to Run

1. Open the project folder in your browser or VS Code.
2. Navigate to any folder such as `Hero Section`, `Login Page`, or `Product Card`.
3. Open the `index.html` file in a browser.
4. For local preview in VS Code, you can use a Live Preview extension or open the file directly.

Example:

```bash
cd "CodeNCraft"
# then open any folder's index.html in a browser
```

## Design Style

The project uses a clean, modern visual language with:

- soft gradients and modern card layouts
- bright accent colors for CTA buttons and highlights
- responsive spacing and typography
- product and dashboard-focused interface patterns
- icon-based navigation and action elements

## Notes

- Assets such as images and icons are included within their respective folders.
- Some folders may use similar brand styling, especially the PixelFit fitness brand theme.
- This is a front-end design practice project and does not include backend functionality, authentication logic, or a database.
