Text Input Fields

Focus inputs to test interactive label and focus states

1. Floating Label
Label moves upward and scales down on focus or input. 
.input:focus ~ label, .input:not(:placeholder-shown) ~ label {
  top: 4px;
  font-size: 0.7rem;
  color: #38bdf8;
}
2. Expanding Bottom Underline
Border line expands outward from the center when active. 
.input-wrap:focus-within::after {
  width: 100%;
}
3. Glowing Pulse Border
Soft neon aura surrounds the border on focus. 
.input:focus {
  border-color: #38bdf8;
  box-shadow: 0 0 12px rgba(56, 189, 248, 0.4);
}
4. Left Icon Integration
Integrated prefix icon that highlights with focus.
🔍 
.input:focus ~ .icon {
  color: #38bdf8;
}
5. Minimalist Inset Shadow
Deep set inner shadow simulating a recessed surface. 
.input {
  box-shadow: inset 0 2px 4px rgba(0, 0, 0, 0.6);
}
6. Dynamic Gradient Border
Reveals a vivid gradient border wrapper upon active focus. 
.input-wrap:focus-within {
  background: linear-gradient(90deg, #38bdf8, #818cf8);
}
7. Corner Bracket Focus Frame
Corner framing brackets appear around the perimeter. 
.input-wrap:focus-within::before, .input-wrap:focus-within::after {
  opacity: 1;
}
8. Glassmorphic Frosted Field
Semi-transparent translucent surface with backdrop blur. 
.input {
  background: rgba(255, 255, 255, 0.03);
  backdrop-filter: blur(10px);
}
9. Animated Placeholder Slide
Placeholder text slides smoothly to the right on interaction. 
.input:focus::placeholder {
  transform: translateX(10px);
  opacity: 0;
}
10. Status Indicator Pop
Pops a green indicator dot when field contains valid text. 
.input:valid:not(:placeholder-shown) ~ .status-dot {
  transform: translateY(-50%) scale(1);
}
