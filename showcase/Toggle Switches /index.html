Toggle Switches

Click controls to test interactive toggle animations

1. Sun & Moon Theme Switch
Transitions between dark mode moon and light mode sun. 
.input:checked + .label .knob {
  transform: translateX(32px);
  background-color: #fef08a;
}
2. Neon Pill Glow
Casts a vivid outer neon glow box-shadow when active. 
.input:checked + .label {
  box-shadow: 0 0 12px rgba(56, 189, 248, 0.5);
}
3. Elastic Liquid Stretch
Uses cubic-bezier spring mechanics for fluid motion. 
.knob {
  transition: transform 0.4s cubic-bezier(0.68, -0.55, 0.27, 1.55);
}
4. Binary ON / OFF Text
Displays explicit status label text inside the track. 
.input:checked + .label::after {
  content: 'ON';
  left: 12px;
}
5. 3D Push Button Inset
Simulates deep tactile groove and raised knob shadow. 
.label {
  box-shadow: inset 0 2px 5px rgba(0,0,0,0.8);
}
6. Minimal Line Track
Slender center rail with an oversized floating thumb. 
.label { height: 12px; width: 60px; }
.knob { top: -8px; width: 28px; height: 28px; }
7. Icon Morphing Switch
Swaps internal state icons (check / cross) on toggle. 
.input:checked + .label .knob::before {
  content: '✔';
  color: #22c55e;
}
8. Vertical Flip Knob
Rotates knob on Y-axis while moving across track. 
.input:checked + .label .knob {
  transform: translateX(32px) rotateY(180deg);
}
9. Segmented Sliding Pill
Dual-option tabbed toggle segment format. 
.radio:checked ~ .seg-label {
  background: #38bdf8;
  color: #000;
}
10. Gradient Sweep Trail
Pulls a colorful background gradient behind sliding knob. 
.input:checked + .label {
  background-position: -100% 0;
}
