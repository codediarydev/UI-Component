Floating Action Bars / Docks

Scroll to explore interactive floating dock animations

1. macOS Scale Magnification
Scales and lifts the icon smoothly on hover.
🏠
🔍
⚙️
🔔
.dock-icon:hover {
  transform: scale(1.35) translateY(-8px);
  background: #38bdf8;
}
2. Floating Lift & Glow
Vertical floating jump paired with a soft glow shadow.
🏠
🔍
⚙️
🔔
.dock-icon:hover {
  transform: translateY(-12px);
  box-shadow: 0 10px 20px rgba(56, 189, 248, 0.4);
}
3. Tooltip Popup Reveal
Displays an animated top label using data attributes.
🏠
🔍
⚙️
🔔
.dock-icon:hover::after {
  opacity: 1;
  transform: translateY(0);
}
4. Active Dot Indicator
Pops an active status dot beneath the hovered icon.
🏠
🔍
⚙️
🔔
.dock-icon:hover::after {
  opacity: 1;
  transform: scale(1);
}
5. 3D Flip Rotation
Flips icon 180 degrees along Y-axis on hover.
🏠
🔍
⚙️
🔔
.dock-icon:hover {
  transform: rotateY(180deg) scale(1.1);
}
6. Bouncing Hop
Continuous playful vertical keyframe animation.
🏠
🔍
⚙️
🔔
.dock-icon:hover {
  animation: hop 0.5s ease infinite;
}
7. Neon Border Wave
Dual inner and outer neon glowing border reflection.
🏠
🔍
⚙️
🔔
.dock-icon:hover {
  box-shadow: 0 0 12px #38bdf8, inset 0 0 12px #38bdf8;
}
8. Glass Pill Expand
Expands the surrounding glass container padding on dock hover.
🏠
🔍
⚙️
🔔
.dock-container:hover {
  padding: 10px 28px;
  border-color: #38bdf8;
}
9. Liquid Morph Fill
Fills background upward smoothly from bottom edge.
🏠
🔍
⚙️
🔔
.dock-icon:hover::before {
  transform: translateY(0);
}
10. Convex Press Down
Simulates physical pressing depth into the bar surface.
🏠
🔍
⚙️
🔔
.dock-icon:hover {
  transform: scale(0.88);
  box-shadow: inset 0 3px 8px rgba(0,0,0,0.8);
}
