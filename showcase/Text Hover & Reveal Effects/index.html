Text Hover & Reveal Effects

Hover over text elements to trigger reveals and animations

1. Gradient Fill Swipe
Sweeps a vibrant gradient fill from left to right.
GRADIENT SWIPE 
.text:hover {
  background-position: 0 0;
}
2. Text Lift & Glow
Lifts upward while casting a neon cyan drop shadow glow.
NEON GLOW 
.text:hover {
  transform: translateY(-4px);
  text-shadow: 0 0 15px rgba(56, 189, 248, 0.8);
}
3. Subtext Slide Reveal
Slides primary text out to reveal active state subtext.
HOVER ME
DISCOVER MORE
.wrap:hover .inner {
  transform: translateY(-40px);
}
4. Masked Spotlight Reveal
Reveals bright colored text layer via clip width mask.
SPOTLIGHT 
.text:hover::after {
  width: 100%;
}
5. 3D Flip Reveal
Executes a full 3D rotation along the horizontal axis.
3D ROTATION 
.text-wrap:hover .text {
  transform: rotateX(360deg);
}
6. Expanding Underline Tracking
Center-outward expanding underline tracker.
CENTER TRACK 
.text:hover::after {
  width: 100%;
}
7. Glitch Shift Effect
Simulates a rapid digital signal jitter on hover.
CYBER GLITCH 
.text:hover {
  animation: glitch-anim 0.2s infinite;
}
8. Letter Spacing Stretch
Expands character tracking width smoothly on hover.
EXPAND TRACKING 
.text:hover {
  letter-spacing: 6px;
}
9. Background Highlight Sweep
Solid background highlight fills behind inverted text.
HIGHLIGHT SWEEP 
.text:hover::before {
  transform: scaleX(1);
}
10. Blur to Sharp Clarity
Transitions obscured blurry text into sharp focus.
FOCUS REVEAL 
.text:hover {
  filter: blur(0px);
  opacity: 1;
}
