Loading Spinners & Indicators

CSS-only animated status indicators and loading states

1. Classic Dual-Ring Spinner
Standard circular border spinner with dynamic top edge color. 
.spinner {
  border: 4px solid #30363d;
  border-top-color: #38bdf8;
  animation: spin 0.8s linear infinite;
}
2. Pulsing Wave Dots
Sequential staggering scaling dot array for subtle activity cues. 
.dots div {
  animation: wave 1.2s infinite ease-in-out;
}
.dots div:nth-child(2) { animation-delay: 0.2s; }
3. Glowing Neon Orbit Ring
Cubic-bezier acceleration paired with high-intensity neon drop shadow. 
.spinner {
  box-shadow: 0 0 12px rgba(56, 189, 248, 0.5);
  animation: spin 0.7s cubic-bezier(0.68, -0.55, 0.27, 1.55) infinite;
}
4. Flipping Square Block
3D perspective cube flipping sequence along multiple axes. 
@keyframes flip-block {
  0% { transform: perspective(120px) rotateX(0deg); }
  50% { transform: perspective(120px) rotateX(-180deg); }
}
5. Expanding Radar Pulse
Concentric expanding circle scaling outward while fading to opacity zero. 
@keyframes radar-pulse {
  0% { transform: scale(0); opacity: 1; }
  100% { transform: scale(1.2); opacity: 0; }
}
6. Continuous Progress Bar
Linear horizontal loading indicator sliding smoothly end-to-end. 
.bar {
  background: linear-gradient(90deg, #38bdf8, #818cf8);
  animation: bar-slide 1.5s infinite ease-in-out;
}
7. Dual Interlocking Rings
Two staggered concentric rings rotating on opposing phase frequencies. 
.ring-2 {
  border-bottom-color: #ec4899;
  animation-delay: -0.45s;
}
8. Bouncing Ball Orbit
Orbiting multi-colored nodes scaling rhythmically in sequence. 
.orbit::before, .orbit::after {
  animation: bounce-orbit 1s infinite ease-in-out alternate;
}
9. Minimalist Circular Dash
High-speed single stroke dash on a muted track line background. 
.dash {
  border: 3px solid rgba(255, 255, 255, 0.1);
  border-left-color: #fff;
}
10. Gradient Spinner Wheel
Smooth conic gradient trail masked into a seamless ring border. 
.spinner {
  background: conic-gradient(from 0deg, transparent 0%, #38bdf8 100%);
  mask: radial-gradient(farthest-side, transparent calc(100% - 4px), #fff 0);
}
