Glassmorphism & 3D Cards

Scroll to explore interactive 3D tilt and frosted glass effects

1. Perspective Forward Tilt
Tilts on both X and Y axes with depth z-translation.
Perspective Tilt Hover to rotate 
.glass-card:hover {
  transform: rotateX(15deg) rotateY(-10deg) translateZ(20px);
  box-shadow: 0 20px 40px rgba(0, 0, 0, 0.6);
}
2. Floating Lift & Glow
Smooth vertical float with an ethereal accent shadow.
Floating Lift Hover to float 
.glass-card:hover {
  transform: translateY(-12px) scale(1.02);
  box-shadow: 0 20px 30px rgba(56, 189, 248, 0.25);
}
3. Dynamic Side Flip
Aggressive Y-axis rotational swing with dynamic shadowing.
Side Flip Hover to swing 
.glass-card:hover {
  transform: rotateY(-25deg) scale(1.05);
  box-shadow: -15px 15px 30px rgba(0, 0, 0, 0.5);
}
4. Frosted Rainbow Glow
Dual gradient aura combined with background glass brightening.
Rainbow Aura Hover for glow 
.glass-card:hover {
  background: rgba(255, 255, 255, 0.1);
  box-shadow: 0 0 25px #ec4899, 0 0 50px #38bdf8;
}
5. Depth Layer Separation
Inner content pops forward independently using preserve-3d.
Pop-out Content
Hover for 3D depth 
.glass-card:hover .content-layer {
  transform: translateZ(30px);
}
6. Conic Border Shimmer
Rotating gradient border sweep visible on hover.
Conic Shimmer Hover for shimmer 
.glass-card::before {
  background: conic-gradient(transparent, #38bdf8, transparent 30%);
  animation: rotate-border 4s linear infinite;
}
7. Convex Press In
Inward scale reaction simulating a physical button press.
Press In Hover to press 
.glass-card:hover {
  transform: scale(0.95) rotateX(-10deg);
  box-shadow: inset 0 0 15px rgba(0,0,0,0.5);
}
8. Neon Edge Reflection
Intense inner and outer border light reflections.
Neon Edge Hover for neon 
.glass-card:hover {
  border-color: #38bdf8;
  box-shadow: 0 0 15px #38bdf8, inset 0 0 15px rgba(56,189,248,0.3);
}
9. Soft Blur Expansion
Deepens backdrop blur density while expanding card dimensions.
Blur Expand Hover to blur 
.glass-card:hover {
  backdrop-filter: blur(25px);
  transform: scale(1.06);
}
10. Diagonal Corner Dip
Asymmetric multi-axis rotation using rotate3d.
Corner Dip Hover to tilt 
.glass-card:hover {
  transform: rotate3d(1, 1, 0, 20deg);
  box-shadow: -10px -10px 25px rgba(56, 189, 248, 0.2);
}
